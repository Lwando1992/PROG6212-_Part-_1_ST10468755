"# PROG6212-_Part-_1_ST10468755" 

The main objective of Part 1 is to plan the RaceDay system, a web-based event management platform tailored for South African road running, walking, and cycling events. This phase involves designing the data model, planning the RESTful API, creating the SQL database script, and managing the project on GitHub, while ensuring a clear understanding of the system's requirements and functionalities.
